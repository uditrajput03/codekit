# CodeKit - Modern SaaS Boilerplates & Starter Kits

Welcome to CodeKit, your go-to solution for ready-to-use SaaS boilerplates and starter kits for modern web development.

## 🚀 Features

- **Frontend**: React + Vite + TailwindCSS + React Router
- **Backend**: Cloudflare Workers + Hono + Prisma ORM
- **Database**: Neon PostgreSQL (serverless)
- **Authentication**: JWT-based with secure password hashing
- **Payments**: CashFree integration
- **Email**: Resend API for notifications
- **Security**: CORS, input validation, password hashing

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TailwindCSS, React Router DOM
- **Backend**: Hono.js, Cloudflare Workers
- **Database**: Prisma ORM, Neon PostgreSQL
- **Authentication**: JWT tokens with secure password hashing (bcrypt)
- **Payments**: CashFree Payment Gateway
- **Styling**: TailwindCSS with custom animations
- **Deployment**: Cloudflare Pages & Workers

## 📋 Included Templates

- **Frontend Kit**: Complete React + TailwindCSS setup
- **Backend Kit**: Cloudflare Workers + Hono + Prisma
- **FullStack Kit**: Complete MERN-like stack
- **NextJS Kit**: Server-side rendering capabilities

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   cd frontend
   npm install
   cd ../backend
   npm install
   ```
3. Set up environment variables in `.env` files
4. Run the applications:
   ```bash
   # Frontend
   cd frontend
   npm run dev
   
   # Backend
   cd backend
   npm run dev
   ```
